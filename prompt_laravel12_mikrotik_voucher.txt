PROMPT PEMBANGUNAN APLIKASI LARAVEL 12
MIKROTIK WIFI VOUCHER MANAGEMENT SYSTEM
============================================================

TUJUAN
------
Bangun aplikasi web management voucher WiFi berbasis Laravel 12 yang berfungsi
untuk mengelola beberapa MikroTik RouterOS secara langsung melalui RouterOS API
atau RouterOS REST API, TANPA menggunakan Mikhmon.

Aplikasi harus dapat:
1. Mendaftarkan beberapa MikroTik.
2. Melakukan test koneksi MikroTik.
3. Memonitor status MikroTik online/offline.
4. Membaca HotSpot Profile dari MikroTik.
5. Membuat voucher WiFi secara batch.
6. Membuat HotSpot User pada MikroTik.
7. Menyimpan data voucher pada database Laravel.
8. Menggunakan queue untuk proses batch.
9. Melakukan retry jika komunikasi dengan MikroTik gagal.
10. Mencegah duplicate voucher.
11. Menampilkan active HotSpot users.
12. Melakukan sinkronisasi data Laravel dengan MikroTik.
13. Membuat PDF voucher untuk dicetak.
14. Menyediakan dashboard monitoring.
15. Menyediakan audit log.
16. Dirancang agar dapat dikembangkan menjadi platform management voucher.

7. IDEMPOTENCY
--------------
Sistem WAJIB mencegah duplicate user pada MikroTik.

Skenario:

Laravel mengirim JKT000001
MikroTik berhasil membuat user
response timeout
Laravel menganggap gagal
queue melakukan retry

Sebelum create ulang:
1. Check username pada MikroTik.
2. Jika sudah ada, anggap sebagai success/synced.
3. Jangan membuat duplicate.

Gunakan:
- unique username
- database unique constraint
- batch ID
- voucher ID
- MikroTik user lookup

Database constraint:
UNIQUE(mikrotik_id, username)

------------------

Queue retry.

Jika sebagian berhasil:

Batch:
PARTIAL

Jika semua berhasil:

Batch:
COMPLETED

Simpan error pada:
vouchers.sync_error

Gunakan retry dengan exponential backoff.
